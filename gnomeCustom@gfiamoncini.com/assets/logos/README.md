<https://github.com/Aryan20/Logomenu>, pasta `Resources/`, commit `cf988c0` (versão 24.8),

  GPL-3.0-or-later do restante do GnomeCustom: são imagens carregadas como dados, uma obra
  separada distribuída junto (agregação), e mantêm a licença de origem.
- **Marcas:** cada logotipo é marca de seu respectivo projeto; o uso aqui é só para
  identificar a distribuição no botão do menu.
- `*-symbolic.svg` são as versões monocromáticas: o Shell as pinta com a cor do texto da barra.
